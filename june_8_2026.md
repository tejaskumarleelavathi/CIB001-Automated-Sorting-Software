## 4. M-Drive Cybersecurity Lockdown — Plan for Tomorrow

### What the lockdown is
The LMDAE572C ships with cybersecurity enabled (CSE mark on label). Must do a one-time setup using the Liberty Software Suite before it accepts any commands.

### Setup process (do with David present)
1. Install Liberty MDrive Software Suite on laptop (Weifeng provided installer)
2. Launch → open **Ethernet Interface**
3. Click **Connect** — software scans network and finds motor
4. Motor should appear at one of: `172.16.9.11`, `172.16.9.12`, or `172.16.9.20`
5. Follow prompts to **set an Ethernet password** — **do this with David present, he needs to know the password**
6. Motor unlocks, blinking stops, motor ready to accept commands

### Important
- Do NOT set the password without David present
- Password must be known by David and Weifeng
- After unlock, the motor IP address needs to be confirmed and added to the driver config
